# Nightmare · конструктор поддержки

Один главный Telegram-бот подключает других ботов по токену, как Livegram. Пользователь нажимает «Добавить бота», отправляет токен из BotFather и получает бота поддержки. Вопросы приходят владельцу в личку или в группу. Ответы подписываются `Ник [Роль]`.

## Запуск сервиса

Токен **главного бота** находится в `E:\nightmarehelp\config.py`, в `BOT_TOKEN`. Для смены главного бота замените это значение. Владельцем подключённого бота автоматически становится человек, который прислал его токен.

Python: от 3.10 до 3.14.

Запустите сервис двойным щелчком по `E:\nightmarehelp\start.bat`. Он использует локальное окружение Python и оставляет окно открытым даже после ошибки. Если сервис уже работает, повторный запуск перезапустит его с обновлёнными файлами. Открытие `bot.py` или `manager.py` через Python в Windows тоже включает этот запуск.

```powershell
cd E:\nightmarehelp
.\start.ps1
```

Если PowerShell запрещает скрипты, используйте `start.bat` или:

```powershell
cmd /c start.bat
```

Переменная окружения `BOT_TOKEN` имеет приоритет над значением в файле. Остановка в терминале: `Ctrl+C`. Все подключённые боты работают, пока запущен сервис и есть интернет. Одновременно работает один экземпляр сервиса из этой папки.

Если сервис работает в фоне, найдите его PID:

```powershell
Get-CimInstance Win32_Process | Where-Object { $_.Name -match 'python' -and $_.CommandLine -match 'E:\\nightmarehelp\\manager.py' } | Select-Object ProcessId
```

Для остановки конкретного процесса: `Stop-Process -Id ЧИСЛО_ИЗ_PROCESSID`.

## Подключение своего бота

1. Откройте главного бота и нажмите `/start`.
2. Нажмите **«Добавить бота»** или отправьте `/addbot`.
3. Создайте отдельного бота у [@BotFather](https://t.me/BotFather) через `/newbot` и пришлите его токен главному боту. Можно переслать сообщение BotFather целиком. Токен главного бота для этого не подходит.
4. Нажмите **«Открыть бота»** и запустите подключённого бота через `/start`. Теперь он может присылать вам вопросы.
5. В подключённом боте установите `/nickname ВашНик`, при необходимости — `/role Владелец`.
6. Разместите ссылку на подключённого бота для пользователей. Их сообщения будут приходить вам через него. Отвечайте через «Ответить» на карточку или пересланный вопрос.

Одному пользователю можно подключить несколько ботов. Разные пользователи управляют только своими ботами. При повторной отправке токена того же бота подключение обновляется, настройки сохраняются. Подключённый бот не может одновременно работать в Livegram или другом запущенном сервисе с тем же токеном.

## Группа поддержки

1. В главном боте откройте **«Мои боты»**, выберите бота и нажмите **«Добавить в группу»**.
2. В настройках группы включите **«Темы»**. Добавьте подключённого бота **администратором** с правами **«Управление темами»** и **«Удаление сообщений»**. Вы тоже должны быть администратором группы.
3. Отправьте в группе `/setgroup@username_подключённого_бота`. Если ссылка добавления передала `/start connect` и права уже выданы, привязка выполнится автоматически.
4. Каждый сотрудник задаёт `/nickname Ник`. Если ботов несколько, адресуйте команду конкретному: `/nickname@username_бота Ник`.
5. Ответьте на карточку или пересланный вопрос обычным сообщением. Пользователь получит ответ с подписью сотрудника.

После привязки новые вопросы приходят в группу. Повторной командой `/setgroup` можно заменить группу. Прежняя группа перестаёт принимать вопросы и отправлять ответы. Сообщения без ответа на обращение остаются в группе. Анонимные администраторы должны писать от собственного аккаунта.

Каждому игроку создаётся тема **«Вопрос от пользователя · @ник»**; если username нет, используется имя в Telegram. Все его следующие сообщения идут в эту же тему. Сотрудники отвечают через «Ответить», чтобы разговоры команды не отправлялись игроку случайно.

Кнопка **«Закрыть обращение»** на карточке или `/close` внутри темы закрывает обращение. Через **10 минут** бот удаляет тему вместе со всеми сообщениями и удаляет связи сообщений из своей базы. Новое сообщение игрока до удаления снова открывает тему и отменяет удаление. После удаления для нового вопроса создаётся новая тема. Открытые темы удаляются после **48 часов** без вопросов и ответов. Проверка удаления выполняется раз в минуту и возобновляется после перезапуска сервиса. Закрытие темы через обычное меню Telegram также запускает таймер удаления.

Сроки задаются в `config.py`: `CLOSED_TOPIC_DELETE_MINUTES` и `TOPIC_IDLE_HOURS`. Удаляются только созданные ботом темы обращений. Личная переписка игрока остаётся в его Telegram; суммарная статистика и блокировки сохраняются. Если право удаления забрали, бот сохраняет связь с темой и повторяет попытку удаления после восстановления прав.

## Управление в главном боте

| Команда или кнопка | Действие |
| --- | --- |
| `/start` | Главное меню |
| `/addbot`, `/connect` | Подключение бота или обновление токена |
| `/bots`, `/mybots` | Список своих ботов |
| «Мои боты» → бот | Статус, группа, количество пользователей, вопросов и блокировок |
| «Отключить» | Остановить бота и удалить его токен из сервиса |
| «Подключить снова» | Подключить бота повторно; настройки сохраняются |
| `/cancel` | Отменить ввод токена |

## Команды в подключённом боте

| Команда | Действие | Доступ |
| --- | --- | --- |
| `/setgroup` | Привязать группу | Владелец бота, администратор группы |
| `/nickname Ник` | Установить подпись, до 40 символов | Участники группы, владелец в личке |
| `/role Владелец` | Назначить `[Владелец]` себе или настоящему владельцу ответом на его сообщение | Владелец бота или владелец группы |
| `/role Куратор` | Назначить `[Куратор]` ответом на сообщение сотрудника | Владелец бота или владелец группы |
| `/role убрать` | Снять роль ответом на сообщение сотрудника | Владелец бота или владелец группы |
| `/role Куратор 123456789` | Назначить роль по Telegram ID участника группы | Владелец бота или владелец группы |
| `/close` | Закрыть обращение внутри темы | Участники группы поддержки |
| `/ai` | Ответом на текст вопроса подготовить черновик ответа ИИ | Участники группы поддержки, владелец в личке |
| `/banuser` | Ответом на вопрос заблокировать автора | Администраторы и владелец |
| `/unbanuser` | Ответом на вопрос снять блокировку | Администраторы и владелец |
| `/unbanuser 123456789` | Снять блокировку по Telegram ID | Администраторы и владелец |
| `/help` | Инструкция | Все пользователи |
| `/myid` | ID аккаунта и чата | Все пользователи |

Без установленного ника ответ не отправляется. На ответ сотрудника можно отвечать повторно, продолжая диалог. На «Ответ доставлен» отвечать не нужно. Блокировки действуют внутри конкретного бота и сохраняются после перезапуска. `/banuser` работает только ответом на карточку или вопрос, доставленный ботом. Обычное сообщение участника группы или ответ сотрудника не подходят. «Куратор» — назначенная владельцем подпись, для неё не нужны права администратора. Назначать и снимать роли может только пользователь, подключивший бота, или фактический создатель текущей группы. Старые роли, назначенные сотрудниками себе до этого обновления, сбрасываются; владельцы должны выдать их заново.

## Ответы с помощью ИИ

Бесплатный ИИ работает через анонимный API Pollinations без API-ключа. Ответы короткие; у бесплатного сервиса бывают ограничения и перебои. При недоступности бот сообщает об этом, обычные ответы сотрудников продолжают работать.

1. Задайте себе `/nickname ВашНик`.
2. Ответьте командой `/ai` на текст вопроса или подпись фото, доставленного ботом. Можно добавить указание: `/ai объясни коротко`.
3. Проверьте черновик в группе. Кнопка **«Отправить игроку»** отправляет его с вашим ником и ролью. Кнопка **«Отмена»** удаляет черновик. Отправить его может только запросивший сотрудник.

Вопрос и указание сотрудника передаются сервису ИИ. Автоматических ответов игрокам нет. Черновики хранятся не более 10 минут. Факты о проекте для ИИ задаются в `AI_KNOWLEDGE` в `config.py`: добавляйте туда только проверенную информацию.

По желанию можно подключить [OpenRouter](https://openrouter.ai/settings/keys): создайте личный ключ и задайте переменную окружения `AI_API_KEY`. Тогда используется OpenRouter с моделью `openrouter/free`; адрес и модель задаются в `AI_BASE_URL` и `AI_MODEL`. Чужие ключи не нужны.

## Сообщения и данные

Поддерживаются текст, фото, видео, файлы, голосовые и стикеры. Подпись добавляется в текст или описание медиа. У стикеров, кружков и слишком длинных сообщений подпись приходит отдельно перед содержимым. Форматирование ответов сохраняется. Части альбома передаются отдельными сообщениями. Если Telegram запрещает пересылку или копирование, бот сообщает об ошибке.

`data/manager.sqlite3` хранит подключения. Токены зашифрованы; `data/tokens.key` содержит ключ. Сообщение с токеном удаляется из чата, если Telegram разрешает удаление. У каждого бота отдельная база `data/ID_БОТА.sqlite3` с группой, никами, ролями, блокировками и связями сообщений. Тексты обращений в базу не записываются. Активные боты запускаются автоматически после перезапуска.

Для переноса остановите сервис и сохраните **всю папку `data`**, включая `tokens.key`. Для запуска также нужны `manager.py`, `bot.py`, `config.py` и `requirements.txt`. Все токены используются локальным сервисом.

Проверки без Telegram и сети:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```
